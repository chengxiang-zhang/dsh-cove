# 记忆：持续理解与有边界的交接

职责：让同一个 Superagent 跨对话、项目和会话代次延续理解，保存决定及理由，减少老板重复解释。目标设计。

边界：记忆不是授权，不是未经验证的运行状态；检索到的旧事实必须带时间与来源。知道某项信息不等于可以向当前受众说出或交给执行体。

## 真源与运行上下文

OpenViking 是可移植偏好、技能和持久知识的唯一真源。Superagent 运行账本保存事件、事项、会话绑定、决策及知识引用；可保留带 OV URI、版本、同步状态和失效条件的受控缓存，不建立第二套可独立修改的偏好或技能权威。

尚未发布的经验候选属于运行记录，状态必须明确。生成或更新可移植技能按既有 OV 写入通路与治理规则执行，不直接写本地 SKILL.md 镜像。OV 暂不可用时运行事实仍可记账，候选排队；无法确认的权限与知识不从模型记忆补造。

## 保存什么

| 内容 | 必需信息 | 用法 |
| --- | --- | --- |
| 用户目标与偏好 | 原话、作用域、生效条件、来源版本 | 减少重复解释，不能扩权 |
| 决策及理由 | 选项、取舍、约束、被否决路径、适用范围 | 防止换会话后重提已否决方案 |
| 事项前情 | 当前要求、执行分工、成果、失败方法、待解决问题 | 续接与交接 |
| 项目知识 | 项目身份、约束、约定与外部真源引用 | 不同项目准确分开 |
| 工作方法候选 | 触发场景、改进方法、反例、评估结果 | 由规则模块决定是否采用 |
| 关系与职责上下文 | 谁提出、替谁办、谁可见、长期职责引用 | 处理老板与他人的不同责任 |

不以「同 topic 同 kind 只能一条」抹掉多项目或多人的事实。冲突至少按主体、范围、话题和有效条件判断；新原话只在适用范围内取代旧原话，不能全局覆盖。

用户明确表达的个人汇报偏好默认跨其项目，例如先讲结论和建议，再展开技术细节。针对项目或一次任务的纠正留在相应范围；局部纠正只在其范围内覆盖通用偏好。范围无法确定时先保留在可确认的较窄范围。

## 检索与上下文编译

先按任务和受众缩小范围，再检索事实、决策、前情与相关方法。返回引用、摘要、来源时间和不确定性；必要时沿引用链读取原始材料。

上下文缺失时系统自行读取允许的交接或派调查 Agent，不默认要求老板重发。对正在执行的事项，验收条件、停止意图和硬边界不能因 token 预算被丢掉；大体量内容保留摘要加可追溯引用。

## 可见性与用途

`canUse` 与 `canSay` 分离，但按实际接收者、目的、项目范围和授权求值，不能只按「老板在群里」这样的类别判断。

- 私聊原文默认只用于该主体的私聊；扩大披露范围需要明确授权。
- 群聊含多个人时，发言材料必须对全部接收者可说；新增成员重新求值。
- 给执行体的提示词是一次信息传递，执行器、宿主和委派目的都需校验；不能借子 Agent 绕过隐私。
- 无需披露原文的行为偏好可编译为最小提示；派生提示也要检查是否泄露语义，不能把「没有同字串」当安全证明。
- 出口字面扫描只作兜底；真正保障是输入裁剪、资料来源标记、受控引用与泄露反例测试。

资料、日志、文档和执行体报告作为不可信数据，不得修改系统身份、权限或工具规则。引用用户原话也必须验证来源，不能让报告中伪造的「老板说」变成授权。

## 交接与证据索引

协调者可以通过受控工具登记交接文档，保存写入者、所属事项、产物版本、可见性与来源。文档内容由人或执行体产生，协调者可编写协调简报；不存在「模型永远不能登记交接文档」的限制。

读取先摘要和目录，按需展开；超出单次限额分页，不悄悄截掉关键验收条件。产物存在不代表内容正确，验收仍由验收模块负责。

## 契约、依赖与失败处理

```text
recall(query, scope, audience, purpose) → sourced views
recordDecision(subject, alternatives, reason, sources) → reference
prepareHandoff(commitmentRevision, executorAudience) → bounded context + refs
proposeKnowledge(entry, source) → candidate / OV publication reference
```

依赖协议与世界模型。规则读取候选而不另造知识库；桌子与判断使用已经过滤的内容。

来源不可读、版本过期、事实冲突分别暴露，不自动选最方便的一条。恢复后核对 OV 引用版本；过期观察可退休，用户明确约束不能因近期未使用而自动删除。

验证跨桌纠正、冷恢复、跨项目同话题不覆盖、群成员变化、执行体提示词泄露和假用户原话注入。扩展记忆抽取器声明来源、字段、默认可见性与反例，不拥有独立授权判定。
