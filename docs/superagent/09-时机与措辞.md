# 时机与措辞：主动推进，按需沟通

职责：组织唤醒信号、通知与对话表达，让老板不必盯运行，同时能随时了解真实情况。目标设计。

边界：本模块不决定执行策略，不自行发消息；协调循环由托管协调负责，对人输出经内核出口。

## 唤醒来源

用户输入、Agent 结果与待答请求、操作回执、产物与测试变化、职责观察、依赖恢复、权限变化及到期复查都可触发判断。事件去重合并；轮询作为兜底。长时间无事件也要按职责检查，不把「没有信号」当作永久不判断的理由。

职责内已授权且目标明确的工作直接进入事项循环，不限制为「每周三个提案等老板批准」。未经授权的新方向可以提案；未回复不产生新授权，但其他授权内工作继续。

检查周期按风险、变化速率、依赖与已有证据调整，留最晚复查时间。对话繁忙不能饿死后台职责；后台工作也不能阻塞停止和用户查询。

## 对外沟通

| 情境 | 行为 |
| --- | --- |
| 受理 | 简要说明理解、必要假设和接下来的工作；估时有依据才给范围，不强制编一个 N 分钟 |
| 用户查询、讨论或纠偏 | 及时回应，按问题复杂度完整解释；用户不需要等执行体结束 |
| 内部重试、换方法、修复环境 | 系统自主处理并留痕，常规情况不打扰 |
| 执行体提问或审批 | 秘书按现有上下文和授权接答；确需用户时汇总具体待决点、证据及推荐，保留原请求关联，不转发技术待办充当处理 |
| 模块或阶段成果通过 | 按原目标汇报可用结果、证据及剩余责任，不把阶段完成称为全部完成 |
| 待发布 | 由秘书集中提供当前候选、前置证据、风险和补救/观察计划，请求具体发布授权；等待不停止其他工作 |
| 已完成验收及约定交付 | 给结果、关键证据、产物入口和真实限制 |
| 目标可能无法达成 | 说明影响与已采取行动；确有用户决定才提一个准备充分的问题 |
| 授权边界或重大产品取舍 | 提供具体方案、推荐与默认不越界动作；没有回复不能视作批准 |
| 长期职责摘要 | 汇总变化、已解决与未解决事项；无有价值变化可安静 |

低打扰不等于隐瞒重大延期、永久障碍或错误结果。技术故障不变成老板的待办，但影响已承诺结果时应如实告知；告知与要求用户调度是两回事。

可能影响用户已依赖的承诺时，以用户最后还能有效调整安排的时点为预警边界，即使尚无事项需要其拍板。预警给出证据及不确定性、影响、补救、用户是否需要行动、下一次更新时间。对外承诺的更新时间作为持久检查点，独立于普通提醒限额；到点须主动给结论或如实说明仍未解决的原因与下一检查点，风险解除也要收口。已有证据显示普通波动可在该边界前消化时，由系统内部跟进。

## 长度、频率与隐私

通知默认短摘要，可链接详情；分析讨论、复杂交付与用户要求展开时允许足够篇幅。通道长度限制用分页或文档承载，不截掉关键事实。统一 100 词、每日固定三次等不作为协议硬约束。

通知合并、静默时段与频率是可配置策略；紧迫风险、明确在等的交付和正在进行的对话不能被总额度无声吞掉。延期、折叠或抑制的原因可查询。

发送前根据最新实际受众、授权、事项版本校验。在已授权且包含非老板受众的通道中标明代理身份，这不启用代接他人请求；不编造时间、范围或外部承诺。字面扫描只作隐私兜底，内容裁剪与用途校验见记忆模块。

## 投机与正式工作

明确委托或已授权职责下，可先只读调查、组织尚未采纳的方案，记录来源、有效期和引用。闲聊按 [判断](08-判断.md) 归位；职责内已明确且获授权的维护可以正式受理执行。

投机采纳率用于调整观察范围，但低采纳率不自动等于低价值；一次避免重大错误可能有价值。不能用 token 成本取代结果价值，也不能无限无目标巡查。

## 查询与控制

status 应能概览多个项目、在办事项、长期职责、当前专业负责人及执行体、责任缺口、未关闭审查问题、风险、等待、下一步与最近成果，并可按项目/事项展开。状态来源是账本加标注时间的远端事实，不是模型猜测。

支持明确范围的停止、暂停职责、人工接管与归还；控制语义见协议和世界模型。面板只是这些状态与操作的展示，低于托管闭环优先级；不创建第二份状态。

摘要不是唯一活性监控。时钟或服务异常由独立健康机制发现，不能把「老板发现今天没有日报」当恢复方案。

## 契约、依赖与验证

```text
dueSignals(now, sources) → deduplicated triggers
classifyCommunication(event, impact, userContext) → reply/notify/brief/silent
render(messageIntent, audience, channelLimits) → message proposals
status(scope, detail) → sourced current state
```

依赖规则、记忆、内核与协议；通过事实事件与托管协调连接。扩展观察源、模板和通道展示不绕过出口。

验证后台自主推进、对话全双工、重大失败可见、常规恢复不扰人、复杂解释不被截断、静默期边界与多项目状态准确。空简报和过期完成消息应被抑制；真正等待用户的决定不能隐藏到无人可见的日志。
