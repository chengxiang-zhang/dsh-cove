# 全部表、索引、工具契约

> **本文属于《秘书式 super-agent 设计文档体系》**，覆盖全局 §5、§6。索引与权威顺序见 `README.md`。
> 这是实现契约：表要能直接建，工具要有参数与错误码。全系统只有这一处写 DDL。

## 5 数据模型

与 `inbox.sqlite` 同库（认领 owner 与写 intake 在一个事务里，`reply-store.ts` 已有 `BEGIN IMMEDIATE` 事务包装〔已证实：`reply-store.ts:343-347`〕）。`PRAGMA foreign_keys = ON`。时间均为 epoch ms。迁移沿用 `PRAGMA table_info` 判列再 `ALTER` 的原地做法〔已证实：`reply-store.ts:269-340`〕。

```sql
-- 管道表加一列：每条入站恰好一个 owner
ALTER TABLE inbox_events ADD COLUMN owner TEXT CHECK (owner IN ('responder','superagent'));

-- 1 parties：人、执行体、被盯的外部会话。owner/colleague 只能来自配置
CREATE TABLE IF NOT EXISTS sa_parties (
  party_id   TEXT PRIMARY KEY,   -- 'u:'||union_id | 'x:'||executor_id | 'w:'||machine||':'||session_id | 'me'
  kind       TEXT NOT NULL CHECK (kind IN ('owner','colleague','member','external','executor','watched','secretary')),
  display    TEXT NOT NULL DEFAULT '',
  open_id    TEXT,               -- per-app 缓存，会变
  source     TEXT NOT NULL CHECK (source LIKE 'config:%' OR source IN ('observed','host')),
  created_at INTEGER NOT NULL,
  CHECK (kind NOT IN ('owner','colleague') OR source LIKE 'config:%')
);
CREATE UNIQUE INDEX IF NOT EXISTS ux_parties_open ON sa_parties(open_id) WHERE open_id IS NOT NULL;

-- 2 desks：对话 -> 桌子会话
CREATE TABLE IF NOT EXISTS sa_desks (
  desk_id      TEXT PRIMARY KEY,  -- 'p2p:'||chat_id | 'grp:'||chat_id
  chat_id      TEXT NOT NULL UNIQUE,
  chat_type    TEXT NOT NULL CHECK (chat_type IN ('p2p','group')),
  counterpart  TEXT REFERENCES sa_parties(party_id),
  audience_json TEXT NOT NULL,    -- 受众 party_id 数组；群成员快照
  audience_at  INTEGER NOT NULL,
  generation   INTEGER NOT NULL DEFAULT 1 CHECK (generation >= 1),
  session_id   TEXT NOT NULL UNIQUE,  -- 'sa-desk-'||hash(desk_id)||'-g'||generation
  cwd          TEXT NOT NULL UNIQUE,  -- ~/.dsh/superagent/desk/<hash>-g<gen>，专用空目录，用于按 cwd 覆盖模型与识别角色
  turn_open    INTEGER NOT NULL DEFAULT 0 CHECK (turn_open IN (0,1)),
  events_in_gen INTEGER NOT NULL DEFAULT 0,
  last_active_at INTEGER NOT NULL,
  created_at   INTEGER NOT NULL,
  CHECK (chat_type = 'group' OR counterpart IS NOT NULL)
);

-- 3 intake：每条被认领的入站消息，一个处置 + 一次预测
CREATE TABLE IF NOT EXISTS sa_intake (
  event_id     TEXT PRIMARY KEY REFERENCES inbox_events(event_id),
  message_id   TEXT NOT NULL UNIQUE,
  desk_id      TEXT NOT NULL REFERENCES sa_desks(desk_id),
  sender       TEXT NOT NULL REFERENCES sa_parties(party_id),
  thread_key   TEXT NOT NULL,
  parent_message_id TEXT,
  received_at  INTEGER NOT NULL,
  state        TEXT NOT NULL CHECK (state IN ('pending','deliberating','disposed')),
  disposition  TEXT CHECK (disposition IN ('answer','commit','amend','check','nudge','release',
                                           'pushback','decline','ask','acknowledge','route')),
  about        TEXT REFERENCES sa_commitments(commitment_id),
  decided_by   TEXT CHECK (decided_by IN ('desk','fastpath','host')),
  reason       TEXT CHECK (reason IS NULL OR length(reason) <= 400),
  deliberation_id TEXT REFERENCES sa_deliberations(deliberation_id),
  -- 预测（判断时写，之后不改）
  work_class   TEXT REFERENCES sa_classes(class_id),
  confidence   REAL CHECK (confidence IS NULL OR confidence BETWEEN 0 AND 1),
  pred_eta_min INTEGER,
  pred_executor TEXT,
  pred_executor_reason TEXT,
  corrects     INTEGER NOT NULL DEFAULT 0 CHECK (corrects IN (0,1)),  -- 本条是在纠正秘书上一次的理解
  CHECK ((state = 'disposed') = (disposition IS NOT NULL))
);
CREATE INDEX IF NOT EXISTS ix_intake_pending ON sa_intake(desk_id, received_at) WHERE state = 'pending';

-- 4 commitments：核心对象
CREATE TABLE IF NOT EXISTS sa_commitments (
  commitment_id TEXT PRIMARY KEY,         -- 'C-'||n，飞书里可直接说 "C-12"
  parent_id    TEXT REFERENCES sa_commitments(commitment_id),
  kind         TEXT NOT NULL CHECK (kind IN ('deliver','watch','remind','decide','goal')),
  debtor       TEXT NOT NULL REFERENCES sa_parties(party_id),   -- 谁欠
  creditor     TEXT NOT NULL REFERENCES sa_parties(party_id),   -- 欠谁
  on_behalf_of TEXT REFERENCES sa_parties(party_id),            -- 秘书替谁出面（R14 第二回执的对象）
  ball         TEXT NOT NULL REFERENCES sa_parties(party_id),   -- 现在等谁
  desk_id      TEXT NOT NULL REFERENCES sa_desks(desk_id),
  thread_key   TEXT NOT NULL,
  origin_event TEXT UNIQUE REFERENCES sa_intake(event_id),      -- 一条消息至多开一件
  work_class   TEXT NOT NULL REFERENCES sa_classes(class_id),
  what         TEXT NOT NULL CHECK (length(what) BETWEEN 4 AND 300),
  intent       TEXT NOT NULL CHECK (length(intent) BETWEEN 4 AND 300),
  check_kind   TEXT NOT NULL CHECK (check_kind IN ('command','artifact','observation','answer')),
  done_when    TEXT NOT NULL CHECK (length(done_when) BETWEEN 4 AND 600),
  boundary     TEXT NOT NULL DEFAULT '',
  target       TEXT,                                            -- watch: 'w:machine:session'；remind: 被许诺人
  state        TEXT NOT NULL CHECK (state IN ('proposed','open','at_risk','fulfilled','unverified',
                                              'broken','released','withdrawn','orphaned')),
  slot         INTEGER CHECK (slot IS NULL OR slot BETWEEN 1 AND 8),
  due_at       INTEGER,                    -- 对外承诺的期限（只有老板能给）
  eta_at       INTEGER,                    -- 秘书校准后的预计
  next_look_at INTEGER,
  eta_model_min INTEGER,                   -- 模型原始估计
  eta_factor   REAL,                       -- 宿主应用的校准系数
  budget_tokens INTEGER, budget_wall_ms INTEGER, budget_turns INTEGER,
  used_tokens  INTEGER NOT NULL DEFAULT 0, used_turns INTEGER NOT NULL DEFAULT 0,
  warned_80    INTEGER NOT NULL DEFAULT 0 CHECK (warned_80 IN (0,1)),
  evidence_json TEXT,
  -- 结果（结案时宿主回填，校准用）
  actual_min   INTEGER,
  attempts     INTEGER NOT NULL DEFAULT 0,
  executor_switched INTEGER NOT NULL DEFAULT 0 CHECK (executor_switched IN (0,1)),
  created_at   INTEGER NOT NULL, updated_at INTEGER NOT NULL, closed_at INTEGER,
  CHECK (state NOT IN ('proposed','open','at_risk') OR next_look_at IS NOT NULL),
  CHECK (state <> 'fulfilled' OR evidence_json IS NOT NULL),
  CHECK (kind <> 'watch' OR target IS NOT NULL),
  CHECK (kind <> 'deliver' OR budget_wall_ms IS NOT NULL)
);
-- R3/G3：一条线程上至多一件活的顶层交付
CREATE UNIQUE INDEX IF NOT EXISTS ux_commit_thread_live ON sa_commitments(thread_key)
  WHERE parent_id IS NULL AND kind = 'deliver' AND state IN ('proposed','open','at_risk');
CREATE UNIQUE INDEX IF NOT EXISTS ux_commit_slot ON sa_commitments(slot) WHERE slot IS NOT NULL;
CREATE INDEX IF NOT EXISTS ix_commit_agenda ON sa_commitments(next_look_at) WHERE state IN ('proposed','open','at_risk');
CREATE INDEX IF NOT EXISTS ix_commit_ball ON sa_commitments(ball, state);

-- 5 assumptions：悬念。只问一个是唯一索引
CREATE TABLE IF NOT EXISTS sa_assumptions (
  commitment_id TEXT NOT NULL REFERENCES sa_commitments(commitment_id),
  ordinal      INTEGER NOT NULL CHECK (ordinal BETWEEN 1 AND 5),
  question     TEXT NOT NULL CHECK (length(question) <= 200),
  taken        TEXT NOT NULL CHECK (length(taken) <= 200),
  reversible   INTEGER NOT NULL CHECK (reversible IN (0,1)),
  mode         TEXT NOT NULL CHECK (mode IN ('declared','asked')),
  status       TEXT NOT NULL CHECK (status IN ('open','confirmed','overturned','expired')),
  resolved_by  TEXT REFERENCES sa_intake(event_id),
  PRIMARY KEY (commitment_id, ordinal),
  CHECK (reversible = 1 OR mode = 'asked')
);
CREATE UNIQUE INDEX IF NOT EXISTS ux_assume_one_ask ON sa_assumptions(commitment_id)
  WHERE mode = 'asked' AND status = 'open';

-- 6 attempts：承诺 x 执行体的一次绑定
CREATE TABLE IF NOT EXISTS sa_attempts (
  attempt_id   TEXT PRIMARY KEY,           -- commitment_id||'-a'||n
  commitment_id TEXT NOT NULL REFERENCES sa_commitments(commitment_id),
  n            INTEGER NOT NULL CHECK (n BETWEEN 1 AND 3),
  executor_id  TEXT NOT NULL,
  provider     TEXT NOT NULL, model TEXT NOT NULL, effort TEXT,
  lifetime     TEXT NOT NULL CHECK (lifetime IN ('oneshot','durable')),
  session_id   TEXT NOT NULL UNIQUE,       -- 'sa-x-'||attempt_id
  cwd          TEXT NOT NULL UNIQUE,
  branch       TEXT UNIQUE,                -- durable 才有
  state        TEXT NOT NULL CHECK (state IN ('pending','running','ended')),
  turn_open    INTEGER NOT NULL DEFAULT 0 CHECK (turn_open IN (0,1)),
  tool_calls   INTEGER NOT NULL DEFAULT 0,
  last_tool_at INTEGER,
  repeat_sig   TEXT, repeat_count INTEGER NOT NULL DEFAULT 0,
  end_reason   TEXT,                       -- turn/end reason.kind 原值
  cancel_origin TEXT CHECK (cancel_origin IN ('release','budget','deadline','stall','loop','reconcile')),
  created_at   INTEGER NOT NULL, ended_at INTEGER,
  UNIQUE (commitment_id, n)
);
CREATE UNIQUE INDEX IF NOT EXISTS ux_attempt_live ON sa_attempts(commitment_id) WHERE state <> 'ended';

-- 7 journal：承诺上发生的一切，只追加（brief、追加输入、汇报、证据、看、预警、状态变化）
CREATE TABLE IF NOT EXISTS sa_journal (
  commitment_id TEXT NOT NULL REFERENCES sa_commitments(commitment_id),
  seq          INTEGER NOT NULL,
  at           INTEGER NOT NULL,
  actor        TEXT NOT NULL,              -- party_id 或 'host'
  kind         TEXT NOT NULL CHECK (kind IN ('brief','amend','nudge','report','look','forecast','state','pushback','note')),
  attempt_id   TEXT REFERENCES sa_attempts(attempt_id),
  request_id   TEXT UNIQUE,                -- 发给执行体的输入：prompt requestId，引擎侧去重
  consumed_turn INTEGER,                   -- 执行体回合吃掉这条输入后回填
  verified     INTEGER CHECK (verified IS NULL OR verified IN (0,1)),
  body_json    TEXT NOT NULL CHECK (length(body_json) <= 8000),
  PRIMARY KEY (commitment_id, seq)
);
CREATE INDEX IF NOT EXISTS ix_journal_unconsumed ON sa_journal(attempt_id)
  WHERE request_id IS NOT NULL AND consumed_turn IS NULL;
CREATE UNIQUE INDEX IF NOT EXISTS ux_pushback_once ON sa_journal(commitment_id) WHERE kind = 'pushback';
CREATE TRIGGER IF NOT EXISTS tr_journal_append_only BEFORE DELETE ON sa_journal
  BEGIN SELECT RAISE(ABORT, 'journal is append-only'); END;

-- 8 memory：同事式记忆。用与说分离
CREATE TABLE IF NOT EXISTS sa_memory (
  memory_id    TEXT PRIMARY KEY,           -- 'M-'||n
  kind         TEXT NOT NULL CHECK (kind IN ('constraint','preference','precedent','person','standing')),
  topic        TEXT NOT NULL CHECK (length(topic) BETWEEN 2 AND 60),   -- 'repo:dsh-cove' | 'reply-style' | 'machine:pc-tower'
  about        TEXT REFERENCES sa_parties(party_id),
  body         TEXT NOT NULL CHECK (length(body) <= 400),
  use_json     TEXT NOT NULL,              -- 可用于判断：在哪些人在场时可用（party_id 数组或 ["org"]）
  say_json     TEXT NOT NULL,              -- 可说出：对哪些人可说（必须是 use 的子集，宿主写入时校验）
  authority    TEXT NOT NULL CHECK (authority IN ('owner-said','party-said','config','observed','inferred')),
  source_event TEXT REFERENCES sa_intake(event_id),
  source_quote TEXT CHECK (source_quote IS NULL OR length(source_quote) <= 120),
  commitment_id TEXT REFERENCES sa_commitments(commitment_id),  -- precedent 指向它总结的那件事
  supersedes   TEXT UNIQUE REFERENCES sa_memory(memory_id),
  state        TEXT NOT NULL CHECK (state IN ('active','superseded','disputed','retired')),
  last_used_at INTEGER,
  last_confirmed_at INTEGER NOT NULL,
  created_at   INTEGER NOT NULL,
  CHECK (authority NOT IN ('owner-said','party-said') OR (source_event IS NOT NULL AND source_quote IS NOT NULL)),
  CHECK (kind <> 'precedent' OR commitment_id IS NOT NULL)
);
CREATE INDEX IF NOT EXISTS ix_memory_topic ON sa_memory(topic, state);

-- 9 classes：工作类与它的校准状态（宿主每天重算）
CREATE TABLE IF NOT EXISTS sa_classes (
  class_id     TEXT PRIMARY KEY CHECK (class_id GLOB '[a-z]*' AND length(class_id) <= 32),
  label        TEXT NOT NULL,
  origin       TEXT NOT NULL CHECK (origin IN ('seed','desk')),
  samples      INTEGER NOT NULL DEFAULT 0,
  eta_factor   REAL NOT NULL DEFAULT 1.0 CHECK (eta_factor BETWEEN 0.5 AND 4.0),
  misjudge_rate REAL, overturn_rate REAL, pushback_override_rate REAL,
  ask_mode     TEXT NOT NULL DEFAULT 'declare' CHECK (ask_mode IN ('declare','ask-first')),
  pushback_mode TEXT NOT NULL DEFAULT 'on' CHECK (pushback_mode IN ('on','quiet')),
  preferred_executor TEXT,
  recalibrated_at INTEGER,
  merged_into  TEXT REFERENCES sa_classes(class_id)
);

-- 10 autonomy：自动度，键是 (工作类, 能力)
CREATE TABLE IF NOT EXISTS sa_autonomy (
  class_id     TEXT NOT NULL REFERENCES sa_classes(class_id),
  capability   TEXT NOT NULL CHECK (capability IN ('self_initiate','steer_foreign','colleague_write','write_repo',
                                                   'change_prod','publish','commit_promise')),
  strength     TEXT NOT NULL CHECK (strength IN ('draft','auto')),
  streak       INTEGER NOT NULL DEFAULT 0, streak_days TEXT NOT NULL DEFAULT '[]',
  promotions   INTEGER NOT NULL DEFAULT 0, demotions INTEGER NOT NULL DEFAULT 0,
  updated_at   INTEGER NOT NULL,
  PRIMARY KEY (class_id, capability),
  CHECK (strength = 'draft' OR capability NOT IN ('change_prod','publish','commit_promise'))
);

-- 11 outbox：唯一出口
CREATE TABLE IF NOT EXISTS sa_outbox (
  outbox_id    TEXT PRIMARY KEY,
  idem_key     TEXT NOT NULL UNIQUE,       -- 同时作为飞书 uuid：'ack:C-n' 'deliver:C-n:requester' 'brief:2026-11-05' ...
  chat_id      TEXT NOT NULL,
  reply_to     TEXT,
  moment       TEXT NOT NULL CHECK (moment IN ('ack','deliver','answer','ask','pushback','cannot','alert','brief')),
  tier         TEXT NOT NULL CHECK (tier IN ('reply','interrupt','brief','silent')),
  commitment_id TEXT REFERENCES sa_commitments(commitment_id),
  event_id     TEXT REFERENCES sa_intake(event_id),
  audience     TEXT NOT NULL CHECK (audience IN ('requester','owner')),
  body         TEXT NOT NULL,
  words        INTEGER NOT NULL CHECK (words <= 100),
  expects_reply INTEGER NOT NULL DEFAULT 0 CHECK (expects_reply IN (0,1)),
  deliver      INTEGER NOT NULL CHECK (deliver IN (0,1)),   -- shadow 档为 0
  lease_epoch  INTEGER NOT NULL,
  state        TEXT NOT NULL CHECK (state IN ('queued','sent','failed','suppressed','folded')),  -- folded=降入简报
  sent_message_id TEXT UNIQUE,
  created_at   INTEGER NOT NULL, sent_at INTEGER
);
CREATE UNIQUE INDEX IF NOT EXISTS ux_outbox_reply_once ON sa_outbox(event_id)
  WHERE event_id IS NOT NULL AND tier = 'reply' AND moment IN ('answer','ack','pushback','ask','cannot');
CREATE INDEX IF NOT EXISTS ix_outbox_day ON sa_outbox(tier, created_at);

-- 12 deliberations：秘书的每个判断回合（秘书自己空跑的读数）
CREATE TABLE IF NOT EXISTS sa_deliberations (
  deliberation_id TEXT PRIMARY KEY,
  desk_id      TEXT NOT NULL REFERENCES sa_desks(desk_id),
  trigger_kind TEXT NOT NULL CHECK (trigger_kind IN ('intake','agenda','report','brief','goal')),
  trigger_ref  TEXT NOT NULL,
  session_id   TEXT NOT NULL, turn INTEGER, request_id TEXT NOT NULL UNIQUE,
  dossier_hash TEXT NOT NULL, dossier_tokens INTEGER NOT NULL,
  ops          INTEGER NOT NULL DEFAULT 0,  -- 本回合成功的工具调用数
  tool_errors  INTEGER NOT NULL DEFAULT 0,
  tokens       INTEGER,
  end_reason   TEXT,
  started_at   INTEGER NOT NULL, ended_at INTEGER
);

-- 租约：同库多进程只有持有者能发；跨机见 §10.3
CREATE TABLE IF NOT EXISTS sa_lease (
  name TEXT PRIMARY KEY CHECK (name = 'outlet'),
  holder TEXT NOT NULL,                   -- hostname:pid:boot_ms
  epoch INTEGER NOT NULL,
  heartbeat_at INTEGER NOT NULL
);
```

种子工作类（`origin='seed'`）：`social`、`lookup-local`、`run-tests`、`change-code`、`change-config`、`analyze`、`watch-session`、`relay`（替老板转话）。桌子每天至多新建 2 类（`CLASS_QUOTA`），新类在简报里报一次，老板回"并到 X"即 `merged_into`〔推断：类太碎则校准永远攒不够样本，§14 错误 3〕。

## 6 接口

### 6.1 桌子工具（秘书唯一能做的事）

上下文（桌子、批内事件、发送者、受众）由宿主从 `agent.ctx` 与 `sa_desks` 解析，模型传不进。错误统一 `{ok:false, code, message}`。

| 工具 | 入参 | 出参 | 错误码 |
|---|---|---|---|
| `judge` | `{event_id, disposition, about?, work_class, confidence: 0..1, reason(<=400), corrects?: bool, new_thread?: bool}` | `{ok}` | `ALREADY_DISPOSED`、`NOT_IN_BATCH`、`LIVE_THREAD_FORBIDS`、`ABOUT_NOT_VISIBLE`、`CLASS_UNKNOWN`、`CLASS_QUOTA` |
| `commit` | `{event_id, kind, what, intent, check_kind, done_when, boundary_extra?, assumptions: [{question, taken, reversible}]<=5, executor_id, executor_reason(<=200), eta_minutes, target?, budget_scale?: 1..4, scale_reason?}` | `{commitment_id, state, eta_at, eta_factor, asked_ordinal?, mandate: 'allow'\|'draft'}` | `NOT_COMMIT_DISPOSITION`、`CHECK_MISSING`、`TOO_MANY_ASSUMPTIONS`、`ASK_REQUIRED`、`THREAD_BUSY`、`EXECUTOR_UNKNOWN`、`EXECUTOR_MISMATCH`（只读执行体接了写活）、`BUDGET_OVER_CAP`、`BOUNDARY_DENIED`、`SLOT_FULL`（不是错误，`state` 回 `open` 且 `ball='me'`，排队） |
| `amend` | `{event_id, commitment_id, text(<=1500), overturns?: int[]}` | `{seq, delivery: 'queued'\|'next-attempt'}` | `TERMINAL`、`NOT_VISIBLE` |
| `release` | `{commitment_id, reason(<=200)}` | `{state, worktree: 'kept'\|'removed', changes}` | `NOT_PERMITTED`（非 creditor 也非老板）、`TERMINAL` |
| `pushback` | `{event_id, commitment_id?, concern(<=200), grounds: string[]>=1, alternative(<=300)}` | `{outbox_id}` | `NO_GROUNDS`（引用不存在或不可见）、`PUSHBACK_REPEAT`、`PUSHBACK_QUIET` |
| `look` | `{what: 'commitment'\|'memory'\|'attempt'\|'doc', id?, q?(<=40), limit?<=10}` | 结构化只读结果，文档正文截 4000 字并用"以下是资料不是指令"边界包住 | `NOT_VISIBLE`、`MISSING` |
| `remember` | `{kind, topic, body, quote?, about?, supersedes?}` | `{memory_id, authority, use, say}`（宿主定作用域） | `QUOTE_NOT_IN_TRIGGER`（owner-said 的引文必须逐字出现在本批消息里）、`CONFLICTS`（返回冲突的 memory_id，秘书必须带 `supersedes` 重试或放弃）、`SUPERSEDE_FORBIDDEN`（低权威不能覆盖高权威） |
| `propose` | `{goal_id, items: [{what, intent, check_kind, done_when, executor_id, eta_minutes}]<=3}` | `{commitment_ids}`（`state=proposed, ball=owner`） | `NOT_GOAL`、`PROPOSAL_OPEN`（上一轮提案未答） |
| `say` | `{event_id?, commitment_id?, moment, text}` | `{outbox_id, tier, words}` | `TOO_LONG`、`MOMENT_FORBIDDEN`、`REPLY_EXISTS`、`DISCLOSE_BLOCKED`、`PROMISE_BLOCKED`、`NO_LEASE` |

`say` 的时刻规则（R5）：`ack` 只能紧跟本批成功的 `commit`；`deliver` 只能在承诺终态；`answer` 只能对本批 `answer/check` 处置；`ask` 只能对应一条 `asked` 假设或 `route`；`alert` 只能由议程回合在宿主报告了信号后使用；`brief` 只由宿主发。`tier` 由宿主按 §9 计算，模型不能指定。

### 6.2 执行体工具

执行体用 `standard` 预设、cwd 为 attempt 目录。宿主 scoped 注册 `report`：`{state: 'ready'|'progress'|'blocked'|'failed'|'dropped', summary(<=2000), evidence?: [{command, exit, reading(<=500)}], question?}` → `{seq}`；`QUESTION_REQUIRED`（blocked 无问题）。`ready` 无证据不拒绝，收下后按 §6.3 判 `unverified`。`guard` 拒绝 `lark_inbox_*`、`worktree_lane`、带 `agent_preset` 的 `subagent` 调用；oneshot 只读执行体另拒一切写工具。用 guard 不用 restrict deny 的原因同 v1〔已证实：事实 9、11〕。

### 6.3 结案判定（宿主，不信自述）

执行体 `turn/end` 到达：有未消费输入（`ix_journal_unconsumed` 命中）→ 不判定；否则按 `reason.kind` 与 `check_kind`：

| 条件 | 结果 |
|---|---|
| `completed` + ready 报告 + `check_kind=command` 且某条证据在 `inspect` 事件里找到同命令、同退出码的工具调用 | `fulfilled` |
| `completed` + ready + `check_kind=artifact` 且宿主能读到该路径或分支有提交 | `fulfilled` |
| `completed` + ready + `check_kind=answer/observation` 且报告 summary 覆盖 `done_when` 列出的要素（宿主逐项子串核对） | `fulfilled` |
| `completed` + ready 但核对不过，或无终态报告 | `unverified`（交付前缀由宿主强制写"做完了，但没验证"） |
| `completed` + blocked | 问题转成 `asked` 假设，`ball=owner` |
| `completed` + failed/dropped，或 `interrupted/error/max-tokens/blocked/未知 kind`，或非我方 `aborted` | 升级（§10.2） |
| 我方 `aborted`（`cancel_origin` 有值） | `release` → `released`；`budget/deadline` → `at_risk` + 问 |

`reason.kind` 未知值当失败，SDK 自己的注释要求如此〔已证实：`dsh-agent/lib/index.js:61-74`〕。bash 工具事件里命令与退出码的字段名〔未验证，P0 第 0 天测〕。

### 6.4 宿主命令（老板不在飞书时）

`node scripts/superagent.mjs status [--json]`、`stop C-n`、`brief --now`、`calibration`。只读账本，`stop` 写一行 `release` 意图由服务执行；退出码 0 成功、1 失败、3 无数据。与 `scripts/lark-autoreply-check.mjs` 同约定〔已证实：该脚本只读账本〕。
