# 目标、边界与成功标准

> **本文属于《秘书式 super-agent 设计文档体系》**，覆盖全局 §0、§1。索引与权威顺序见 `README.md`。
> 这份文档只回答一件事：**它是什么、不是什么、怎么算成**。想改产品的方向，先改这里。

## 0 一页读完：它和现在的 bot 差在哪

现在的 bot 是**一问一答的对话方**：消息来了起一个回合，回合文本就是回复，回合结束它就什么都不记得要做了〔已证实：`responder.ts:1042` 拼消息文本、`:1084` 以 `queue` 提交，回合结案即 `replied`〕。它没有"在办的事"，没有"等谁"，没有"什么时候该再看一眼"。

本设计的秘书是**一本账加一只钟**：

| | 纯应答的 bot | 本设计的秘书 |
|---|---|---|
| 推动它的 | 消息 | 账上每件承诺自己的时钟；消息只是改账的三种事件之一（另两种：执行体汇报、时钟到点） |
| 核心对象 | 一个回合 | 一件**承诺**：谁欠谁什么、凭什么算完成、现在球在谁手里、下次什么时候看 |
| 接到模糊要求 | 照字面做，或反问 | 先按假设接下，**在受理那一句里把假设说出来**；只有不可逆的那一处才问 |
| 主动发言 | 别处会话跑完就试着说点什么——19 次全是空回合〔已证实：`reply_jobs` 中 `kind=proactive` 的 19 行 `outcome` 全为 `empty`〕 | 只在某件承诺的信号变了时开口（超预估、停滞、到期风险、球到了老板手里） |
| 对自己的认识 | 无 | 每次判断都是一次带数字的预测（估时、执行体、要不要问）；结果回来按类改下一次 |
| 老板的注意力 | 每条回复平权 | 三档：现在打断（每天有额度）/ 今天简报看一次 / 永不出现 |
| 不同意时 | 照做 | 一次有据的异议（引用老板说过的话或校准数字）+ 替代方案；老板坚持就做，并记下"这类事我的异议常被推翻" |

**用真实消息说明差别**（2026-11-04 15:54 到 11-05 12:04 的全部 19 条入站〔已证实：`sqlite3 -readonly $DB "SELECT ... FROM inbox_events"`，本文写作时读取〕）：

| 老板原话 | 纯应答的 bot | 本设计的秘书 |
|---|---|---|
| 「帮我把 dsh-web 仓库里 lark-inbox 的 10 个 spec 逐个文件跑一遍」，8 秒后「别跑剩下的了，只看 responder，把它的用例名按分组列出来」 | 两条各起一个回合 | 两条进同一批（收集窗），第二条推翻第一条的范围：一件承诺 C-n，受理"接了 C-n：只看 responder.spec，按 describe 分组列用例名，不跑。预计 2 分钟"。"不跑"是从"别跑剩下的了"推出的假设，说出来让他能一句话纠正 |
| 「http://dsh.pc-tower.netbird/ 看下这个机器还在运行的会话」→「分析下这个会话，是否开始空跑了」→「你给他发消息，让他好好干活」 | 三次独立问答；最后一句它要么照发"好好干活"，要么说做不到 | 识别为同一件事：老板要的不是一条消息，是**那个会话重新产生进展**。秘书开一件 `watch` 承诺盯住它，并对第三句异议："只发'好好干活'没用，它卡在 X 已 N 分钟。我建议发具体指令'先跑 Y 再决定'，或停掉重派。回 1/2"。之后它每 10 分钟看一眼，空跑就叫老板 |
| 「hi」「你好」「你是谁」「你可以做什么」「12」「谢谢」（10/19 条） | 每条起一个模型回合 | 不开承诺、不进校准；宿主快路径或桌面会话一句话答完。今天的负载里过半是这种，设计不能让它们付"案卷"的成本（§14 错误 1） |

**三个新概念**（全文都在展开这三个）：
1. **承诺与球权**：核心对象不是任务，是"谁对谁承诺了什么、到期没有、现在等谁"。老板的注意力 = 球在他手里的那几件。
2. **议程时钟**：每件开着的承诺都带 `next_look_at`。秘书被时间推动，所以能**事前**报忧，而不是失败后才报。
3. **声明式假设 + 校准**：模糊要求不反问，按假设接下并说出假设；每次判断写成预测，结案时回填实际，按类改它下次的估时、执行体和"先问还是先做"。

## 1 设计输入：真实负载与老板的恐惧

- 负载：19 条 / 约 20 小时，全是私聊〔已证实〕。分类：寒暄与试探 10、本机信息查询 2、动手任务 3（其中 1 条是 8 秒后的范围修正）、图片 1、**监督别的机器上的 agent 会话 3**。并发不是问题，连续性与判断才是〔已证实：同一读数〕。
- 第五类在设计里必须显式成立：老板已经在把 bot 当作"替我看着别的 AI 的人"用，而那些 AI 不是秘书派出去的。原话 2「主动汇报可能的问题」、原话 15「害怕 agent 空跑，转牛角尖」在真实用法里指向的就是它。本设计把"盯一个不是我派的会话"做成一等承诺（`kind='watch'`，§3.7）。
- 恐惧：原话 15 怕空跑。本设计里空跑有两种：执行体空跑，和**秘书自己空跑**——时钟每到点就起一个模型回合、什么都没改。后者是"议程时钟"这个选择带来的新风险，用宿主侧信号预检挡住（§3.7、§14 错误 7）。
