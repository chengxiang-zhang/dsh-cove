# Git graph view provenance

The Git graph view in this directory is an independent implementation for
dsh-cove. It was informed by an earlier Git graph prototype, but it shares no
source files with that prototype: the lane layout, the rendering primitives and
the UI modules were rewritten for this package, and no third-party code is
included here.

see the repository [LICENSE](../../../../../../LICENSE).
