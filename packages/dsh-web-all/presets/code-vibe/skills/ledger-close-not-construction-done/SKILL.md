# 关条 ≠ 施工完成（Ledger Close）

> 一句话：**"我做完了"不是完成；"账本条目被它自己的门证伪过"才是完成。**
> 这一条来自真实翻车：2026-10-29 的 SK03 连续 6 轮"修好了"，账本只从 34 降到 4；每一轮红都不一样，都不是关条。

## 1. 什么时候必须用

- 用户问"完成了吗 / 还有哪些问题 / 能宣布完成了吗 / 现在什么状态"；
- 你准备在回复里说"完成 / 已修复 / 已解决 / 收尾了"；
- 一批 gap/任务结束、准备向下一批推进；
- 交接（handoff）之前。

**不适用**：批次内部的普通进度汇报（那只需四数：开放/阻塞/已关/本会话真关）。

## 2. 判定单位

最小判定单位是**账本里的一行**，不是"这个模块大概能跑了"。
每行必须能回答三件事（关条三元组）：

1. **条目**：哪个 gap / 判据编号（不是"那个问题"）；
2. **自证门**：一条**可复跑**的命令 + 判据（exit code / 计数 / 断言名），且这条门是**条目自己的**门，不是"整个套件绿了"；
3. **证据**：本轮命令输出或运行态回读（截图不算，读数才算）。

三项缺一 ⇒ 这一行**未关**，只能写"施工完成，未关条"。

## 3. 三个禁止

- **禁止拿"门绿了"代替关条**：套件绿只证明"没有已知红"，不证明"这条 gap 的行为成立"。
- **禁止拿"我改完了"代替自证**：改了什么 ≠ 行为成立；必须有门/读数。
- **禁止拿"报告/文档/清单"代替验收**：写了方案不等于做了。
- **禁止自造出口**：自己写的验收条款不算数，标「待用户确认」；与账本证据冲突时取**更严**的一侧。

## 4. 完成前的四问（逐步打勾，答不上就别说完成）

1. 这一行在账本里的编号是什么？现在状态是什么？
2. 它自己的门是哪条命令？本轮跑过吗？exit code 和读数是什么？
3. 有没有"同族红"没处理（换个面又冒出来的同一类缺陷）？
4. 还没关的条目里，哪些是**真的没做**、哪些是**合法 DEFER（有归属 + 到期）**？分别几条？

四问全答完，才允许说"本批关闭 N 条，账本 X→Y，剩余 Z 条（其中 DEFER …）"。

## 5. 时间门（soak / 24h / 探针到龄）

- 时间门**不能**用"我盯着"来关：写下窗口起止时间、到点判定命令、判定人；
- 到点前只允许报"时间门等待中（起点/终点/已运行时长）"，**不允许**每 30 分钟发一轮巡检报告；
- 到点后跑判定命令，用读数关条；提前宣布 = 假完成。

## 6. 输出模板（三行）

```
关条：<编号> <条目> —— 门 `<命令>` rc=0 / 读数 <关键数>
账本：开放 <N>（真未做 <a> · DEFER <b>）→ 本会话关闭 <C>
未关原因（若有）：<一句话，含下一步与到点时间>
```

## 7. 反例（真实）

- 06:00 说"只剩一条判据"，实际同一份契约里还有 3 条会被连带打破，跑了三轮才绿 → 这不是关条，是"没做静态清点"。
- 巡检报告连续 5 轮"覆盖率 1.0 / 0 miss"，但调度 tick 已连续 89 次 FAILED → 报告不是证据，门才是。
- 45 秒压测得出"2C2G 过度配置"，30 分钟持续压测 OOM 两次推翻 → 缺"持续 vs 突发"证据就宣布结论 = 假完成。
