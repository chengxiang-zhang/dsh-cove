# 关条证据判据（EC1–EC8）

| ID | 检查什么 | 怎么查 | 失败示例（实测） |
|---|---|---|---|
| **E1** 命令须当轮实跑 | 台账里的命令必须真出现在同一 turn 的 `tool/call` 参数 | 归一命令串 → 子串匹配 | `grep 'default="minioadmin"'` 在 4,001 次 bash 里 **0 次**；`grep -c 'flock -n'` **0 次** |
| **E2** 读数须是 result 逐字片段 | 且不得只出现在"写台账的正文/heredoc" | 只在 result-only 语料里搜 | 四个采样键只在写台账的 heredoc 里，无任何测量输出 |
| **E3** 命令与读数同一 call→result 配对 | 不能"A 跑、读数来自 B" | callId 配对 + `isError=false` | 某行 EV 命令实跑 `exit 1`，读数取自下一个变体命令；另一行 EV 命令只在迁移**前**跑过（旧值） |
| **E4** 禁竖线 | 单元格不得含未转义 `|` | 写入转义/拒绝 + 门侧列数==表头 | 证据行含 `(A|B|…|R1)_.*` ⇒ `[列数不符]` |
| **E5** 一次关 N 条每条须独立判据 | 禁"一份探针 → N 条结论" | 差值 N vs 证据配对数 M；M<N 且无 `共用探针=` 声明即红 | 17 条关闭、**0 份当轮证据**；另一批 3 条共用 1 份探针且未声明 |
| **E6** 二级证据须标 `source=receipt:` | 回执/正文不得当一级 | result 0 命中、team-message/edit 命中即须标注 | 某行两条关键读数只在 teammate 回执；唯一相关命令是 `No such file` |
| **E7** 量值按"当时"复算 | "表 N 行"必须等于提交时点 | `git show <sha>:<file>` 重算 | 标题写"4 条转入"，提交时点表里只有 4 行（第 5 行是后一批加的） |
| **E8** 跨轮读数标 `读于 T###` | 禁把别批读数当"当轮" | 命中回合须落在声明区间 | 某行引 `71 passed`，唯一出处是**另一批**的 turn |

**判据落地**：`BATCH-STATE` 证据列拆「命令 / 读数 / 复跑校验」三格 + `读于 T###`；
`test_batch_state_contract.py` 至少实现 E1/E2/E4/E5 的负控。做不到自动取 `tool/result` 时，退一步：
每行附 `读于 T###` 并把该轮原始输出片段粘在批次附注里（人工可核）。

**三种最贵的失真形态**：拿二级证据当一级（回执）；命令与读数不是同一条；事后回填/跨批挪用/从未执行。
