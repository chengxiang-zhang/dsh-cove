# 证据目录（单一真源）

## 阶梯（E0–E3）

| 级别 | 含义 | 谁做 | 用在哪 |
|---|---|---|---|
| E0 | 自述 | 执行者 | 仅 T0 纯观点 |
| E1 | 命令 + 退出码 + 读数 | 执行者 | T0 事实 / T1 |
| E2 | 独立复跑（fresh context，只读） | verifier | T2 / T3 关条 |
| E3 | 干净树 + 负控（`git archive`、注入必红） | verifier | T2 数据/运维 / T3 P0 |

## 关条证据判据（EC1–EC8）

1. **命令当轮实跑**：命令必须出现在同一 turn 的 `tool/call`。
2. **读数同源**：读数是同一 call `tool/result` 的原样片段（不是抄写/heredoc）。
3. **配对**：命令与读数来自同一 callId，`isError=false`。
4. **禁竖线**：台账单元格不得含未转义 `|`。
5. **每条一据**：一次关 N 条，每条有自己的只读判据；共用探针声明覆盖。
6. **二级标注**：回执/转述标 `source=receipt:<sender>`，不得填一级读数格。
7. **当时复算**：量值按提交时点复算（"表 N 行"用 `git show` 核）。
8. **跨轮标 `读于 T###`**：禁止把别批读数当"当轮"。

## 门目录

| 门 | 用途 | 失败判据 |
|---|---|---|
| 目标测试 | 行为正确 | 退出码非 0 |
| 负控 | 证明判据能红 | 注入后仍绿 = 失败 |
| 独立复跑 | maker≠grader | 读数不一致 |
| 双向实测 | 生效类 | 只测一边 = 未验收 |
| 下游锚点扫描 | 关条 | `grep -rl` 有引用未改 |
| 批次三格 | 台账 | 命令/读数/复跑缺一 |
| KILL 五条件 | 裁决不做 | 任一缺失 |
| `--require-nonempty` | 覆盖类 | 空集当绿 = 失败 |
| 真基线 | 归因 | 口头归因 = 不算 |

## KILL 五条件

① 能力/对象确实不存在（只读 0 命中）；② 证据当轮可复跑；③ 不由越权/无授权实验得出；
④ 判据不放宽；⑤ merge 目标存活且 P0 未静默降级。状态用 `closed-by-decision:<原因>`，不得与 blocked 并存。
