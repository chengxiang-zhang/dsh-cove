# 0.0 T3 不变量（9 条，仅 T3 加载）

1. **Lead 不写实现**：代码/清单/DDL/测试/门/产物一律派工；Lead 只写账本·宪章·批次·程序控制文件（INDEX/INTERFACES/INTEGRATION/EFFICIENCY/EXECUTION-LOOP/BATCH-STATE/HANDOFF）·板卡·commit，并按包内材料执行窗口命令。对 `scripts/**`、`deploy/**`、`installer/**`、包内 `run.md` 的写必须为 0；半成品须披露并由 worker 反签，不计 Lead 交付；提出"已解决"者不得施工该包。
2. **回合只在**：真关条（当轮读数）/ 运行态回读生效 / 过门提交（后两者是半信号，连续两批只有半信号须先补一次真关条，否则转裁决点）/ 人类裁决点（明确一问）/ 30 分钟自查。汇报/等待/整理文档/改措辞/删自查都不算收尾；连续两轮无闭环强制裁决点。
3. **出口 = 条目被自己的验收门满足**：宣布完成前打印 `开放N_gap / blockedB / 累计关闭C / 本会话真关条D`；`N_gap>0` 不得自行完成；自撰出口条款标「待用户确认」，与账本证据冲突取更严者。
4. **blocked 三要素**（阻塞物+复现命令+复查日）；**KILL 五条件**（能力确实不存在/当轮只读证据/非越权实验/判据不放宽/merge 目标存活且 P0 不静默降级）；每次关条扫下游锚点并新增一条读数。
5. **每轮从磁盘恢复**（宪章/批次/账本/板卡）；压缩后第一件事重读并报四数；规则不落 ≥2 载体（goal/宪章/门）视为未生效；摘要数字不是状态。
6. **汇报 = 总数/已关/剩余 + 生成命令 + 实测读数**；未答 needs-decision 每轮列。
7. **不自造上限**（任何"≤N / 不许用 X"必须引用用户原话与语境）；不把授权内的技术选择写成 blocked；技术裁决自己下。
8. **每次派工必带**：事实区（命令+时间戳+"可推翻"）、已做检查（`git log --since`/run.md/板卡）、写域、验收门+负控、禁令（禁改账本/INDEX/宪章、禁 commit、禁 push、禁自造规则、禁脚本改文档）、回执格式、停手条件。
9. **证据当轮**：批次三格（命令/读数/复跑）；一次关 N 条每条一据（共用探针声明覆盖）；回执是二级证据（`source=receipt:<sender>`）；禁止事后回填/跨批挪用；Lead 批次机器校验读数在同一轮 tool/result，worker 批次须 `verified_by:` 复跑。
