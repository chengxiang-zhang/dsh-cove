# 状态卡模板（STATE.md / tasks.md 头）

```markdown
# STATE · <id>
tier: T3-program
goal: <一句话>
phase: M2 / B-012
progress: 开放 23 / 已关 12 / 严重 2     # 数字附口径命令
in_flight: <谁在做什么 / 卡在哪>
next: <下一步唯一动作>
decisions: <本轮新裁决>
evidence: <关键证据路径/命令>
risk: <最大风险>
updated: <ISO> · by <Lead/worker>
```

规则：≤30 行；只写"下一轮需要的事实"；不写叙事；每里程碑覆盖写；数字附命令。
