# 13. 反模式速查（完整版与证据见 `references/anti-patterns.md`）

| # | 反模式 | 一句话纠正 |
|---|---|---|
| A01 | 自己动手 / 窗口伴随改动 / 改真源忘投影 | Lead 对 scripts·deploy·installer·run.md 的写必须为 0 |
| A02 | 角色漂移无声明 | 每张派工单写角色基线；职责变了要声明作废旧写域 |
| A03 | 验收读到半写树 | 先取停手信号，或只验收已提交 commit |
| A04 | 判者变造者 | 提出"已解决"者不得造该包；必须复用则第三人复核 |
| B01 | 轮级空转 | 单轮必须有账本变化/读数/提交之一 |
| B02 | 阶段空转 | ≥10 轮无关闭无生效 ⇒ 停手复盘 |
| B03 | 低成本动作替代 | 只改 blocker 措辞 ≥2 轮即空转 |
| B06 | 假完成 | 宣布完成必须打印四数；N>0 不得 complete |
| B07 | 关条口径通胀 | 判据只由条目自己的门定义；改判据不用于本批关条 |
| B08 | 批量标签化（32=15+17 累计；`ddc6b85` 17/17 仍写 blocked，4 条 P0/critical） | KILL 五条件；blocked 与"裁决不做"不能共存；P0 不降级 |
| C01 | 判据漂移/自评自门 | 判据变更需落盘+披露+非执行者复核 |
| C03 | 关条打断锚点 | 关条前 `grep -rl` 下游锚点并同批修 |
| C09 | 判定不可复现 | 同批换框架重判 ⇒ 第一次作废复盘 |
| D01 | 报绿与实测不符 / 掩码闸门 | `if pytest; then commit; else 不提交; fi`，禁 `| tail` |
| D03 | 语义错配假绿 | 门语义逐字对齐目标系统 + 运行态回读 |
| D06 | 关条无当轮读数 / 证据后填 | 台账证据拆"命令/读数/复跑"三格并机器校验 |
| E01 | 重复派工/同片多派 | 派工前查板卡+`git log --since`+run.md |
| E03 | queued 当唤不醒 | 改派前 `list_agents` + 查最近产出 |
| E04 | 缺写令牌/让路式并发 | `pgrep` 写令牌；一环境一 writer；反复冲突上 flock |
| E08 | 仪式性派工/零回执 | ≥3 次 0 回执标不可用；区分已投递/已确认/已产出 |
| F02 | 规则只在对话里 | 三载体至少两处，否则按未生效 |
| F03 | 自造/装饰性上限 | 任何 ≤N/不许 X 必须标来源 |
| A24 | 重试循环无缺口枚举 | 成本≥20min 的动作先列剩余缺口 + 声明轮数上限 |
| A25 | 观测窗口内改判据 | 窗口期内只许加严，且每次改动留负控与可比性说明 |
| E09 | 取证来源错标 | 账本归宿的"谁跑的/命令/读数"必须先在 run.md 落行并有回执 |
