# 9. 空跑 / 作弊 早期检测（每轮自查）

| 指纹 | 阈值 | 立即纠正 |
|---|---|---|
| 连续 N 轮账本净变化 = 0 | 2 轮 | 停轮整改：列候选 + 为什么关不掉 + 一问 |
| 连续 N 轮累计净变化 0、关闭 0、无生效 | 10 轮 | 阶段空转：改验收路径或停手复盘（**不许第 4 次同类试错**） |
| 同一账本条目连续只改 blocker 措辞 | 2 轮 | 低成本动作替代：该轮计空转，改去做真关条 |
| 连续 N 轮派工 = 0 且自己在改文件 | 1 轮 | 停手，把活拆成卡派出去 |
| 回合工具数 ≤3（单工具轮）连续出现 | 3 轮 | "报表轮"，合并进真实工作轮 |
| 同一红/同一失败模式重复 | 3 次 | 改验收路径或降级换卡 |
| 同一 gap 的重建/重试 | 2 次 | 先枚举剩余缺口 + 声明轮数上限，再跑（真实：9 次重建逐缺陷发现） |
| 自己发明上限/禁令，或把授权写成阻塞 | 任意 | 撤回；任何"≤N/不许 X"必须标来源 |
| 提交信息与实测读数不符 | 任意 | 跟进更正 commit + 留档 |
| 只做只读诊断/台账算术，不碰验收门 | 1 轮 | 回到"取一条 → 按它自己的门关掉" |
| 向零回执成员投递（仪式性派工） | 3 次 | 标不可用换人；"已投递"≠"已委派" |
| 目标/计划里的数字无生成命令 | 任意 | 先补命令再派工 |

**"看循环"判据**（真实：同一类冷重建失败重复 6 次才发现）：
不要只问"这一轮为什么红"；要问**"最近 3 轮的红是不是同一类？失败模式在移动还是原地打转？"**
红点每次不同 ≠ 在推进；每轮都暴露"下一个隐式假设"说明验收路径选错了（换路径，不是继续修）。
