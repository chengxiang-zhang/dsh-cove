# 11. 环境窗口（G2/G3 唯一合法姿势）

每次窗口 = 一次不可回滚风险，必须按序（六要素）：

1. **只读基线**：改动前读数 + 备份/快照位置（写进台账"材料"列）。
2. **材料先行**：判定谓词、幂等性、回滚 SQL、双向读数口径必须已在包内，**时间戳早于执行**
   （真实翻车：集群写早于材料 5 分钟；红线在违规 76 分钟后才写）。
3. **写令牌**：执行前 `pgrep -af 'staging-rebuild|cargo|docker build'`（含 git 操作）确认为空；
   一环境同一时间只有一个 writer；同类冲突连续 3 次后必须上仓库级 `flock`，不许再靠人肉。
4. **单批 apply**：一批只做一件事；批内每项已有 G0/G1 证据；Lead 只按材料执行。
5. **双向实测**：正控（该通的通）+ 负控（该拒的拒）；只测一边 = 未验收。
6. **回滚在手 + 回读留档**：可执行回滚命令；下发后回读生效读数（"apply 成功"≠"生效"）。

**审计/查询纪律**：全表扫描类查询必须带分区谓词（真实：全表 `json_query` 扫描 + 批量删 S3 触发 CN SIGSEGV ×3），
一条硬规则下发给全队并进门。
