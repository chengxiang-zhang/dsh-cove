# 项目宪章模板（`EXECUTION-LOOP.md`）

> 复制到 `<repo>/docs/specs/<program-id>/EXECUTION-LOOP.md`，按项目改。
> **这是执行期唯一操作真源**：与其它派工/效率文档冲突时，以本文件为准。
> 只追加式维护：§1~§9 是规则，文末是轮次日志。

```markdown
# 执行环 · <program-id>（长目标任务 loop 宪章 + 轮次日志）

> 本文件是 <N> 个施工包的执行宪章：定义工作单位、单轮协议、选卡、写域、证据、预算与停止条件，
> 并在文末以**只追加**方式记录每一轮。

## §0 出口（先写出口，再开工）

**出口判据 = 唯一账本里每一条的归宿都可判**，但**"归宿可判"不等于"可以宣布完成"**：
- `open` 只能靠**关条**清零（当轮读数 + 下游锚点扫描）；`blocked` 三要素**不能**替代关条；
- `accepted-risk` 必须单列（接受人 + 复核日 + 重开条件），不计"未处理"，也不计"已解决"；
- **宣布完成必须同屏打印四数**：`开放 N_gap / 其中 blocked B / 累计关闭 C / 本会话真关条 D`；
  `N_gap>0` **不得**自行 complete；自撰出口条款标「待用户确认」，与账本证据冲突取更严者。
**不是**"包全部 done"，**不是**"卡全部 completed"，**不是**"报告写完"。
**R0 豁免**：开环轮（建四件套、建板卡、登记写域）允许以"完成开环四件套 + 一条可复跑读数"收尾，
但必须在轮日志注明 `R0=setup`；计数器（空转/关条）从第一条 `closed*` 之后才开始计。

出口报告必须给三行实数：
`code-ready x/N · 窗口已生效 y 项 · 外部 blocked z 项（三要素齐）`
+ 账本：开放 A（blocked B + accepted-risk C），非终态 0。

**禁用词**：`code-ready` 不得表述为「完成/上线/已生效/已交付」。运行态结论必须有点位读数。

## §1 单位与粒度

- **轮（round）** = 一次 assistant 回合（系统按步注入 goal_round；回合结束 = 我停止调用工具并输出）。
- **批（batch）** = 一个可独立验收的工作单元，跨多个回合。**轮不是工作单元。**
- **切片** = 卡内最小施工单元，必须标 G 档：

| 档 | 典型改动 | 必须的验证 | 动不动环境 | 预算 |
|---|---|---|---|---|
| **G0 单点** | 一个函数/一条规则/一处措辞 | 单元先红后绿 + 1 条负控 | 不动 | 秒~分钟 |
| **G1 包内切片** | 多文件、契约形状、生成物一致性 | 包内用例 + 契约门；生成物 `git diff`/`cmp` | 不动 | 分钟级 |
| **G2 生效批** | 需在环境生效的配置/策略/镜像 | 批内每项先有 G0/G1 证据；批级**一次** apply + 回读 | 动，一次、攒批 | 一次窗口 |
| **G3 跨模块/系统** | 链路、恢复、安装、守恒 | 联调矩阵 + 基线复算 | 单窗口串行 | 计划窗口 |

**禁止为单个改动开窗、禁止改一点就重启服务。**

## §2 单轮协议（9 步，每轮同一模板）

| 步 | 动作 | 完成判据 | 上限 |
|---|---|---|---|
| S1 | **恢复态** | 宪章尾 + 批次台账尾 + 账本 §0 + 板卡 + 相关包 run/VERSION 可读 | 2min |
| S2 | 选卡 | 按 §3 优先级取 1 张 | 2min |
| S3 | **必要性自证（硬前置）** | 跑本卡存在性/复现用例，得四判定之一 | 10min |
| S4 | 冻结判据 | 先红（负控必须能红）+ oracle-freeze 声明 | 10min |
| S5 | 施工/派工 | 单切片；G0/G1；G2/G3 转批次 | 卡内 |
| S6 | 自证 | 命令 + 退出码 + 读数；新红 vs 存量红（基线比对） | — |
| S7 | 留档 | 包 run.md 追加结构化行（≤10 行）+ 宪章轮次 1 行 | 3min |
| S8 | 记账 | 待关条累计；**账本只在收口点由 Lead 批量改** | — |
| S9 | 提交 | 过门后提交；message 带包 id + 证据命令 | — |

**S3 四判定**：`仍存在`（施工）/ `已解决`（关条不施工）/ `描述过期`（先修描述）/ `无法判定`（写 `missing=`，换卡）。
台账/上一轮结论**只是线索**，不得当判据引用。

**S0 摘要作废（新增）**：压缩摘要里的任何计数（开放数/包状态/窗口数）一律作废，S1 从磁盘现场重取；
摘要里新立的规矩必须当轮落到本文件或门并附出处，否则按"未授权新规则"处理。

## §3 选卡与依赖

- **板卡纪律**：派工即 `claim`；收口即 `complete`；blocked 用 subject 前缀 `[BLOCKED: 原因]`；
  每轮 S1 必须把板卡与 `run.md`/`VERSION` 对账，发现脱节当场修。
- **优先级**：根包/门与证据类 → 契约类 → 出口类 → 窗口类；同级 `P0/critical/high` 优先。
- **反向依赖只走** `INTERFACES.md` 的接口条目 + 双写窗口，不得直接改下游文件。
- 不参与选卡的历史卡（规划卡/窗口卡）留在板上时，必须标注"勿据其 ready 开工"。

## §4 写域与并发

- **真实约束只有三类**：① 团队人数上限（满了复用 inactive）；② 用户红线（重编译与冷重建不并发、不推上游、不越权清理他人资源）；③ 共享文件单写。**不许自造并发上限**；
  任何"≤N / 不许用 X"必须标注用户原话与语境，否则删除。
- **环境写令牌（新增）**：写集群前 `pgrep -af 'staging-rebuild|cargo|docker build'`（含 git 操作）确认为空；
  一环境一 writer；同类冲突 ≥3 次必须上仓库级 `flock`，不许继续人肉 pgrep。
- **Lead 独占**：账本、INDEX、INTERFACES、INTEGRATION、EFFICIENCY、本文件、批次台账、`CURRENT`、板卡、全部 commit；
  **包内 `VERSION/contract/tests/plan/run` 与 `scripts/**`、`deploy/**`、`installer/**` 一律 worker 写**。
- **worker 只写**：本包目录 + INDEX 声明的写域文件。领卡前与"当前活跃写域"对账。
- **只读发现类默认并行扇出**；写入类按写域分派；一个候选只允许 1 实现 + 1 验收。
- **跨仓/开窗动作**归单独批次，环内只落契约与红测试。

## §5 证据纪律（防假绿）

1. 每条结论带 `rerun=<命令>` + 退出码 + 读数；无命令的结论不得进关条。
2. T-case 必带负控，负控必须红；oracle-freeze 后改预期必须回 `plan.md`。
3. **他证**：G1 级以上结论由 fresh-context agent 只看 diff + 证据复核（不复用执行者记忆）。
4. **抽样反查**：每 10 轮抽 1 个已关项重跑存在性用例。
5. 假绿黑名单：`health` / `smoke` / Pod Running / 脚本存在 / "重启过"。
6. 负控失败必须归因分类：`implementation | product-ux | plan | test-oracle | environment | new-request | unknown`。
7. **引用哪道门，就当场把它跑绿**；"报绿的门其实是红的"是最常见的假绿。
8. 门只在**静默点**跑：有活跃写者时 repo 级红不可归因；归因不明记 `in-flight`。
9. **他证三件套（新增，任一缺失不算验收）**：① 干净 checkout 复跑（`git archive` + 临时仓）；
   ② 负控真能红（不是 skip、不是恒真）；③ 功能可用性（凭据/入口/环境能否让合法路径通过）。
10. **证据必须是当轮的（新增）**：批次台账证据拆「命令（当轮执行原文）/ 读数（该命令输出片段）/ 复跑校验」三格；
   门校验读数字符串出现在同一 turn 的 `tool/result`；teammate 回执只能作二级线索并标 `source=receipt:<sender>`；
   跨轮引用必须标 `读于 T###`。审计实测：38 行里 8 行证据失真。
11. **覆盖类判据必须 `--require-nonempty`**：范围内为空 ⇒ `inconclusive` 且非零退出，不许"删到 0 就绿"。

## §6 记账与关条

- **账本单写**：Lead 执行「删条 + 文末索引 + §0 重算」，同批完成。
- **关条触发**：取先到者——① 平台侧证据齐（命令读数 + 非执行者复核）；② 模块边界。**不等窗口**。
- **完成度双口径（不许混用）**：包维度（`code-ready`）与账本条目数分列，互为指示器，不得互相冒充。
- **收口判据分层**：包级 = 本包用例红→绿（或明确 blocked）；效果级门若红由窗口类造成 ⇒ 记 `blocked(window)`，不阻塞包级。
- **关条下游锚点扫描（新增）**：删条前 `grep -rl "GAP-<id>" docs/ scripts/ deploy/`；有引用者同批改锚点，
  并跑"被删条目引用方"的反查门集，不只跑记账门（审计实测：一次 11 条关条把全绿契约门打成 4 failed/9 skipped，两天未回绿）。
- **判定可复现（新增）**：同一条目、同一证据，换框架重判导致结论翻转（实测 29→0→7/7）⇒ 第一次作废并复盘；
  两次判定差异 >50% 按事故记。
- **KILL 五条件（新增）**：① 能力/对象确实不存在（只读 0 命中）；② 证据当轮可复跑；③ 不由越权实验得出；
  ④ 判据不放宽；⑤ merge 目标存活、P0 不得静默降级；`blocked` 与"裁决不做"不得并存。
- **提交纪律**：允许先提交防丢工作，但 message 必须带 `verification: pending`；复核翻案用跟进提交撤销；**严禁把"已提交"写成"已验收"**。
- `run.md` 只允许结构化行；模块收口压缩成一行结论回填账本与 `CURRENT`。

## §7 预算与检查点

| 项 | 值 |
|---|---|
| 轮次预估（计划数，写进宪章；**不是** `create_goal` 的 `max_goal_rounds`） | 按实测节奏定（例：N 包 × 4~6 切片 ≈ 75 轮，取 90 留余量）；超预估只换会话/拆批，不掐目标 |
| 自检 | 每 5 轮一行：推进数 / 预算燃烧 / blocked 清单 / 下一批 |
| 人工检查点 | 每个模块收口停一次：3 行报告 + 暂停等确认 |
| 单卡超时 | G0 ≤15min、G1 ≤45min |
| 反停滞 | **口径优先序**：轮级（连续 2 轮净变化 0 ⇒ 停轮整改）→ 卡级（连续 3 轮同卡无跃迁 ⇒ 降级换卡）→ gap 级（同一 gap 重建/重试 **2 次** ⇒ 先列剩余缺口 + 声明这次实验的轮次上限，写进轮日志）；三者可叠加，先触发者先执行 |
| 禁空等 | poll ≤30s、同类等待 ≤10min、等待期必有 fallback 卡 |
| 规则载体 | 新规则必须同轮落到 ≥2 of {goal objective, 本文件, 门}，否则视为未生效 |
| 自查装置 | 连续 2 轮空转时禁止删除/暂停 30 分钟自查；必须升级为"候选 + 一问" |

### 效率红线

1. 一轮最多 1 个"深度调试"切片；同一定位循环 ≤2 次，超了拆切片。
2. 改函数前先读它的契约（参数语义/边界/已有处理）。
3. G0 同类小改动一轮最多 5 个、攒一次提交；G1 一轮 1 个。
4. 板卡只建一次、只改一次。
5. 证据块 ≤15 行：超出只留 `rerun=` + 读数。
6. 每轮开头 30 秒三问：这张卡是否最高价值？能否 5 分钟证伪？会不会滑进细节？
7. 自指污染禁令：结论文本提到退役词/历史 id/门模式字面值时写成不自命中形式。
8. 归档条目出范围：判定前先查账本删除索引。

## §8 停止 / 阻塞 / 复活

| 情形 | 动作 |
|---|---|
| 无 ready 卡 | **立即终止 goal**，出出口报告（禁空转烧预算） |
| 窗口/云/授权/数据缺失/他人文件受限 | 卡置 `blocked` + 复活条件 + owner，换卡继续 |
| 预算耗尽 / 用户改向 / 三连轮无进展 | 硬停，出「已推进 / 未推进 / 待裁定」三行报告 |

## §9 抗压缩与幂等

- **每轮从磁盘恢复**（宪章 + 批次台账 + 账本 + 板卡 + run/VERSION），不吃对话记忆。
- 任何口头决定必须落进「裁决记录」或本文件，否则视为不存在。
- 幂等键 =（卡 id, 切片 id, 证据命令）。
- 每轮结束必须留下一次状态跃迁或显式 blocked，否则记为空转（计入反停滞）。
```
