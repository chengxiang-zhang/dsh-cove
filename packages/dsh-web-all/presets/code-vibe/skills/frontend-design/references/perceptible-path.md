# 可感主路径卡（全流程唯一必需对象）

> 同一对象被引用三次，不是三个产物。
> 反模式：[`scheme-antipatterns.md`](./scheme-antipatterns.md)。

## 五字段

| 字段 | 写什么 |
|------|--------|
| **谁** | 目标用户 / 角色 |
| **什么触发** | 进入场景的入口与动机 |
| **第一次成功看到/得到什么** | 可观察的用户结果（非内部状态） |
| **怎么观察到** | 人点验步骤或可机跑断言 |
| **非目标** | 本切片明确不做 |

## 落盘位置

| 阶段 | 落点 |
|------|------|
| Shape | 产品方案脊骨（可写在 demand / module README / 方案卡） |
| Spec | `tests.md` 的 **T-001**（或索引中第一个 success 主路径）Then = 「怎么观察到」 |
| Verify | 人类验收包第 1 步 = 同一主路径 |

## 闸

- 「怎么观察到」若命中 [`scheme-antipatterns`](./scheme-antipatterns.md) → **不得**请确认方案；`check_spec` 对 T-001 Fail。
- 增长 / 激活 / 教育类：可感主路径优先于检查点账本；Checklist 最多附录。
