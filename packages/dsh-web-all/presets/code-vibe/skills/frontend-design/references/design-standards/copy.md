# Copy（UX Writing 合同）

> 蒸馏自 Vercel writing 习惯、WIG Content、空态/错误最佳实践。
> 与 [product-judgment.md](./product-judgment.md)、[LOAD-MAP.md](./LOAD-MAP.md) 交叉。

## 总则

1. **具体动词**：按钮写清结果（「保存 API Key」），禁空壳「提交 / 确定 / Continue」。
2. **第二人称**；短句；一句一个意思。
3. **数字用数字**（「8 个部署」）。
4. 省略号用 `…`；单位不换行可用窄不换行空格意识（`10 MB`）。
5. 产品专有名、代码、ID：`translate="no"` 意识（i18n 时）。

## 按钮与链接

| 场景 | 写法 |
|------|------|
| 主 CTA | 动词 + 对象 |
| 次行动 | 文字链或次钮；勿第二主色实心钮抢权 |
| 取消 | 「取消」可；勿与主 CTA 同视觉权 |
| 危险 | 「删除项目」含对象；确认框重复对象名 |

## 错误（What / Why / Next）

```text
标题：发生了什么（人话）
说明：为何（若可知）
行动：下一步（重试 / 改字段 / 联系谁）
```

禁：「出错了 / Something went wrong」无下一步。
字段错贴字段；系统错可用 toast，但仍要可行动。

## 空态文案

| 态 | 文案结构 |
|----|----------|
| First-run | 缺什么 + 为何重要 + 主 CTA 标签 |
| 筛选为零 | 「无匹配」+「清除筛选」 |
| 无权限 | 与空区分；谁可申请 / 如何切角色 |

## 权限 / 计费 / 破坏

- 权限：说明缺口，不假装空列表。
- 计费：额度/到期静态可见，不藏悬停。
- 破坏：确认文案含范围（「将删除 12 个成员的访问权」）。

## consumer / growth

- CTA = 下一动作（「领取优惠」非「立即体验」空话堆）。
- 信任点可测、可溯；禁虚构评价。
- 法律/隐私链接可见。

## product 口径

- 指标名与宿主/数据口径一致；歧义写在 caption。
- ID 展示可读名；复制 ID 为次要。
- **禁实现黑话上屏**（`rule/no-impl-jargon`）：主体、投影、registry、shadowing、内部风险码等 → 用人话或产品名；见 [product-judgment.md](./product-judgment.md)。
