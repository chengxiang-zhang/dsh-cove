# Exemplars（正反例）

> 条款抽象，例子可复现。Agent 实现前可扫一眼同 `page_kind`。

## list

| | 好 | 坏 |
|--|----|----|
| 结构 | 筛选+表+URL；数字右齐 | 卡片墙当订单管理；筛选只在内存 |
| 空态 | 「还没有项目」+创建 vs 「无匹配」+清筛选 | 两种同一句「暂无数据」 |
| 行 | 可读名；ID 复制次要 | 主列 UUID |

## detail

| | 好 | 坏 |
|--|----|----|
| 布局 | 工单用主栏+右轨分组属性 | 20 字段一长表按 DB 序 |
| 编辑 | 点状态 pill 即改 | 「编辑」打开大模态改一个枚举 |
| 面包屑 | 壳层已有 ID，正文 h1 用标题 | 正文再堆一个巨大 ID |

## settings

| | 好 | 坏 |
|--|----|----|
| 导航 | Personal/Workspace + 段深链 | 单页 40 开关无 URL |
| 危险 | 底部分区「删除工作区」+ 打字确认 | 删除键夹在主题色旁边 |

## dashboard

| | 好 | 坏 |
|--|----|----|
| KPI | 一主三从；带 +12% 对比 | 四块一样大无基准 |
| 图 | 同高；口径在旁 | 库默认白 tooltip；假 3D |

## overlays

| | 好 | 坏 |
|--|----|----|
| 新建 | Modal 短表 | Sheet 却强 dim 当 Modal |
| 行预览 | Sheet 保留列表 | 每次预览都整页跳转又返回 |

## judgment（配置 / 授权 / 分发）

> 见 [product-judgment.md](../product-judgment.md)。先 Job，再抽屉。

| | 好 | 坏 |
|--|----|----|
| IA | 「谁可以用」「怎么拿到」「怎么改」分层可见 | 主体/投影/高风险术语堆在首屏 |
| 选择 | 唯一搜索入口；多选后一次「添加 N 项」 | 先切「人/部门/组」再搜；搜一个加一个 |
| 分发 | 可见范围与默认开启分两步决策 | 「权限策略」一词包办谁能看+怎么发 |
| Brief | 落盘 Job Brief + 人话验收 | 直接画线框再补故事 |
