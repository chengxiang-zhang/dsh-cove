# Color Roles（语义色）

> 只许下列**角色**；施工用 `var(--…)` 或宿主 token 名，禁止组件内任意 hex。
> 无宿主 DS 时用「默认值」列。覆盖 → [README.md](./README.md)。

## 1. 角色表

| 角色 | 含义 | 无宿主默认（Light） |
|------|------|---------------------|
| `canvas` | 最底层画布 | `#F5F5F5` |
| `surface` | 主表面（面板/卡片底） | `#FFFFFF` |
| `surface-muted` | 次级表面（表头、斑马弱底） | `#FAFAFA` |
| `text` | 主文 | `#1F1F1F` |
| `text-secondary` | 次文 | `#595959` |
| `text-disabled` | 禁用/占位 | `#BFBFBF` |
| `border` | 默认线 | `#F0F0F0` |
| `border-strong` | 强调线 | `#D9D9D9` |
| `accent` | **唯一**主行动 / 链接 / 焦点强调 | `#1677FF`（可被宿主品牌替换） |
| `accent-hover` | accent 悬停 | `#4096FF` |
| `accent-active` | accent 按下 | `#0958D9` |
| `success` | 成功状态 | `#52C41A` |
| `warning` | 警告 | `#FAAD14` |
| `error` | 错误/危险 | `#FF4D4F` |
| `info` | 信息 | `#1677FF` |
| `chart-1`…`chart-6` | **仅**图表分类色 | 宿主或实现时再定；不得用于主按钮 |

暗色主题：宿主提供；未提供时保持对比度 ≥ WCAG 底线，勿纯 `#000` / `#FFF` 硬编码正文。

## 2. 使用纪律

1. **先灰度建层级**（字重/尺寸/对比），最后上色。
2. 颜色只用于：**状态**、**唯一主 CTA/链接**、**品牌强调**、**图表系列**。
3. 同级信息不用颜色区分；状态须配文案或图标（不只靠色）。
4. 一屏 **一个** `accent` 主行动色；勿多品牌色抢权。

## 3. 硬禁止（输出扫描）

| 禁止 | 原因 |
|------|------|
| `#6366F1` / `#818CF8` / 同类「AI 紫靛」作 accent | 通用模型默认味 |
| 装饰渐变、glow、grain、玻璃拟态抢主任务 | product 与多数 consumer 主路径 |
| 纯黑 `#000` 大面积正文或阴影 | 改用 near-black / 多层淡影 |
| 用 success 绿表达「推荐/更省钱」而无状态语义 | 学 Vercel：色须有意义 |
| 预设彩虹色当主按钮 | 分类色只给 tag/chart |

## 4. 与宿主

- AGENTS 声明 `primary` / 品牌色 → 映射到 `accent*`，替换默认蓝。
- 使用 antd / Geist 等 → 直接用其 token，角色语义对齐本表，不另起 hex。
