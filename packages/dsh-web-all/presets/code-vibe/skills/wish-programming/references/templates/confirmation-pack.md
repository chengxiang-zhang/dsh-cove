# confirmation-pack — 用户故事包（确认门工件）

> 用途：前台 PM 与用户确认需求理解的**唯一格式**。写完先过内部 red-team（「用户会在哪里误解这份包？」），再发给用户。
> 用户确认后：conductor 执行 `journey.sh --confirm --by <用户>` 落工件，并把确认结论逐条登记进 product.md 决策记录。
> 禁用词汇表：本文件出现 scope / adminOnly / 治理动作 / 路由 / Schema / 命名空间 / Endpoint / 限流配额 / Gateway 管理 等工程词汇时，必须同段附「（白话：…）」解释——check_spec 机检。
