# module-readme — 模块 README 规范（提案与决策索引，非「单一真源」）

> 位置：`docs/product/modules/<x>/README.md`。定位：该模块的**提案与决策索引**——承载定位、提案状态、决策索引、开放问题。
> 诚实规则：README 之间出现矛盾时，**必须把矛盾显式登记为开放问题或 GAP**，不掩盖、不自行调和。
> 时效标注：复用仓库现状——frontmatter `status:`（active / superseded）+ 提案/未立项/done 状态词 + `updated:`，不另设标注体系。

```markdown
---
status: active
updated: YYYY-MM-DD
---
```
