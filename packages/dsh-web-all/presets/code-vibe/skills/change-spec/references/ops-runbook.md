# 运维单批 Runbook（T2-ops 六要素）

1. **只读基线**：变更前读数 + 备份/快照位置（写进台账/acceptance）。
2. **材料先行**：判定谓词、幂等性、回滚命令、双向读数口径必须在包内，时间戳早于执行。
3. **写令牌**：执行前 `pgrep -af 'staging-rebuild|cargo|docker build'`（含 git 操作）确认无冲突；一环境一 writer。
4. **单批 apply**：一批只做一件事；批内每项已有单元证据；只按材料执行。
5. **双向实测**：正控（该通的通）+ 负控（该拒的拒）；只测一边 = 未验收。
6. **回滚 + 回读**：可执行回滚；下发后回读生效读数（"apply 成功"≠"生效"）。

生产动作：必须有当轮真人授权；无授权只做只读/演练。
