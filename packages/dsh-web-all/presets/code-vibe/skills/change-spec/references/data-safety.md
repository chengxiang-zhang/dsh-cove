# 数据安全门（T2-spec 数据类）

1. **备份/快照**：变更前确认可恢复点（`pg_dump`/快照/对象版本），写进 acceptance 的"回滚"。
2. **dry-run**：优先 `BEGIN … ROLLBACK` 或只读预演；写操作先在事务内验证受影响行数。
3. **回滚 SQL/命令**：可执行，不是"应该可以"；派生可重建的给重建命令。
4. **权限最小化**：用只读/最小角色验证；负控：无权限角色必须被拒。
5. **变更后回读**：受影响行数/约束/索引/视图逐项读回；"执行成功"不算。
6. **不可逆动作**（DROP/TRUNCATE/批量 DELETE）必须有人授权 + 备份 + 二次确认。

禁止：无备份改生产；把 `--force` 当默认；用脚本批量改文档/数据却不留 diff。
